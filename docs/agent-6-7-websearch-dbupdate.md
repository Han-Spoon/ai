# ⑥⑦ 웹서치 · DB 업데이트 에이전트 스펙

> ⑥ 웹서치 에이전트, ⑦ DB 업데이트 에이전트(`catoin-multi-agent-architecture.md` 3번 섹션 참고)의 구현 스펙(API 계약, 관리자 컨펌 플로우, 에러/재시도 처리 등)이 들어갈 문서.

**왜 이 둘을 한 문서로 묶었나**: 두 에이전트는 "웹서치 결과 → 관리자 컨펌 → DB 반영"이라는 하나의 파이프라인으로 강하게 결합되어 있어서, 따로 쪼개면 핸드오프 인터페이스(입출력 형식)가 두 문서에 흩어져 어긋나기 쉬움. XAI(⑧)와는 결합도가 낮아 별도 문서(`agent-8-xai.md`)로 분리함.
